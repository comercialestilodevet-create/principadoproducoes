## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie o conteúdo mantendo a pasta `assets`.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main` / folder: `/ (root)`.
6. Salve.
